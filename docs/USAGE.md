## UIパネル

タイトルバー : ドラッグするとパネルを動かせます
**`H` キー** : パネルの表示 / 非表示を切り替えます
プリセット : 設定を保存・呼び出しできます
影1 / 影2 / リム / サブライト : 各レイヤーの設定です
画面下のボタン : 画像の読み込みと書き出しを行います

起動直後は 影1だけがONで、他はOFFになっています。必要なレイヤーをONにしてください

## パラメータの説明

#### ライト奥行き

0に行くほど影の領域が増え、1に行くほど影の領域が減ります。

#### ライト方向

光がどっちから当たるかを指定します。

#### エッジぼかし

影の境界をどのくらいぼかすかです。0 に近いとアニメ塗りのようにパキッと、上げるほどグラデーションがかかります。影1 と影2 で別々に設定できます。

#### 影色

色をカラーピッカーで選べます。
現状、合成モードは以下で固定されています
影1・影2 : ソフトライト
リム・サブライト : 加算（サブライトは不透明度10％）

#### 影1

メインの影です。

#### 影2

影1 とは別の角度から、もう一段影を落とすためのレイヤーです。影の中のさらに濃い部分を作る、明暗境界線を作る、など

#### リム

輪郭を光らせるレイヤーです。幅でリムの太さ、リム色で色を決めます。光る位置は影1のライト方向に追従します。

#### サブライト

環境光や反射光にあたる補助的な光です。

## プリセット

パラメータ一式に名前を付けて保存できます。

| ボタン | 動作 |
|---|---|
| `＋ 登録` | 今の設定に名前を付けて保存。同じ名前があれば上書き確認が出ます |
| `− 削除` | 選択中のプリセットを削除 |
| `↻ リセット` | 全パラメータを初期値に戻す |

保存したプリセットはボタンとして並び、クリックすると呼び出せます。

プリセットの保存場所（Windows）:

`C:\Users\<ユーザー名>\AppData\LocalLow\<会社名>\<製品名>\ToonPresets\`

中身は JSON なので、バックアップや他の環境への持ち運びはこのフォルダごとコピーします。

## 書き出される PNG

書き出しでは5枚の透過 PNG が出力されます。保存ダイアログで指定したファイル名+以下の命名規則で書き出されます。

`{ベース名}_{レイヤー名}_{ツール内合成モード}.png`

例えばベース名を `toon` にした場合:

`toon_shadow1_softlight.png` 影1
`toon_shadow2_softlight.png` 影2
`toon_rim_add.png` リムライト
`toon_sub_add.png` サブライト
`toon_comp_reference.png` 合成イメージ（プレビューと同じ絵）


レイヤーのトグルを OFF にした状態で書き出しても空のPNGが書き出されます。仕様です。

書き出されたPNGをペイントソフトで重ね直す、加筆する等してご使用ください。

※注意

カンプと、各レイヤーを重ねた見た目は完全には一致しません。
入力画像のサイズ上限は長辺 4096px です。(それより大きいサイズを読み込むと4096pxに縮小されます)
影テクスチャを使った場合、`shadow1_softlight.png` の合成モードは「通常」になります。
（ファイル名は `_softlight` のままなので注意してください）
